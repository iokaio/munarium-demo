# Support

Apache-2.0 includes no support commitment. Ask questions or report defects in this
repository's GitHub Issues. Include the revision, platform, and a minimal
reproduction with private values removed. Vulnerabilities go to
[SECURITY.md](SECURITY.md), not public issues.

The demo is independently buildable and includes its data and operating guides.
Model and infrastructure costs are the operator's responsibility. Munarium
Enterprise is a separate proprietary distribution; this license grants no rights
to it. Commercial enquiries: info@ioka.io.
